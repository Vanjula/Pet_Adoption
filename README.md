# 🐶 Dabang – Pet Adoption & Product Marketplace

**Dabang** is a user-friendly platform where users can **adopt pets** like dogs and cats and **shop for pet essentials** like food, toys, beds, and bowls. The platform ensures a smooth experience for both users and admins, offering adoption request management, product browsing, and pet tracking features.

---

## 🌟 Features

🐾 **Browse Pets for Adoption:** View available dogs, cats, and more with filters for breed and location.  
🛒 **Shop Pet Products:** Buy pet food, beds, toys, bowls, and other accessories from the built-in marketplace.  
📋 **Adoption Requests:** Users can send adoption requests; admins can approve or reject requests.  
📊 **Admin Dashboard:** Admins can manage pet listings, products, and view adoption stats with visual graphs.  

---

## 🛠️ Tech Stack

**Frontend:** React.js / CSS / JavaScript  
**Backend:** Node.js / Express.js  
**Database:** MongoDB  

---

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js  
- npm  

Clone the repo and run `npm install` in both frontend and backend folders to get started!
